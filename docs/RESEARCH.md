Lower-priority comparisons: [OpenVehicleDiag's Cargo manifest](https://raw.githubusercontent.com/rnd-ash/OpenVehicleDiag/main/app_rust/Cargo.toml) is Rust with iced, J2534 and SocketCAN; its visible 1.0.5 release is 2021-05-15. [DDT4All's manifest](https://raw.githubusercontent.com/cedricp/ddt4all/master/pyproject.toml) is Python/Qt, GPL-3.0-or-later, version 3.1.3 with a 2026-08-23 history anchor. [PyRen's ELM module](https://raw.githubusercontent.com/petrikvs/pyren/main/pyren3/mod_elm.py) is Python Renault-focused code; mirror license and recency were not verified. [AndrOBD's Gradle file](https://raw.githubusercontent.com/fr3ts0n/AndrOBD/master/androbd/build.gradle) is Java/Android, current source V3.0.2 with usb-serial support, while retrieved releases lagged. None establishes the target reset.

Other references: [OpenVehicleDiag](https://github.com/rnd-ash/OpenVehicleDiag) is a historical GPL GUI/schema example; [DDT4All](https://github.com/cedricp/ddt4all), [PyRen](https://github.com/petrikvs/pyren), and [AndrOBD](https://github.com/fr3ts0n/AndrOBD) illustrate other vehicle/ELM UX, not Porsche compatibility; [freediag's VAG source](https://raw.githubusercontent.com/fenugrec/freediag/master/scantool/diag_l2_vag.c) implements KW1281, a narrow legacy protocol. PyRen mirror licensing was not verified. Consult each dependency's current license and data terms before reuse.

**Conditional direction:** start with a small offline Python capture/replay core and fake transport because it is quick to test without hardware. If authorized captures establish UDS over ISO-TP, evaluate python-can + can-isotp + udsoncan. If they instead establish another transport, reassess; Rust `ecu_diagnostics` and `mcd-diag-rs` are references, not assumed dependencies. Freeze selected package versions at implementation time. Do not create a universal stack or write-capable reset path from model-year inference.

Before an oil-reset proposal, establish market/variant, exact ECU hardware/software, adapter/firmware, actual transport and state-owning module, lawful procedure or known-compatible before/after capture, affected fields/units/bounds, inspection interval distinction and controlled validation plan. See [safety boundary](SAFETY_AND_EVIDENCE.md).

Checked 2026-10-13 against [TypeSafe coding-agent guidance](https://docs.typesafe.ai/introduction/coding-agents), [agent skill](https://docs.typesafe.ai/agent-skill), [API](https://docs.typesafe.ai/api), [model list](https://docs.typesafe.ai/models), and [known limitations](https://docs.typesafe.ai/model-jaggedness/jev-1.13). No TypeSafe plugin, key, hook or adapter was installed. An official skill teaches API use; it does not automatically route Claude Code tools, paths or retries. Jev chooses among bounded options; it is not a code generator or safety authority.

For a separately approved adapter, deterministic code must first enumerate allowed candidates and reject unauthorized tools, roots, targets and retry counts. Only ambiguous semantic choices go to the pinned evaluated Jev model (`jev-1.13.0` at research time). The model may return an existing candidate ID or abstain, never a new path, command, protocol byte, timeout, checksum or permission. Validate schema, membership, freshness and confidence policy; failures return control to Sonnet without silent action. Record a sanitized state hash, policy and model versions, candidates, decision, confidence, latency and result. Replay recorded validated choices for reproducibility; live model calls are not byte-for-byte deterministic.

Evaluate against a labeled offline corpus with ambiguous and adversarial cases. Compare accuracy, abstention, latency and cost to simple rules. Keep numeric counts, backoff, idempotence and arithmetic in code. Review the destination and data minimization before any API use; never send raw captures, VIN, private code or credentials without authorization. Claude hooks may be a future integration surface, but no hook or advisor interception is claimed here. See [Claude hooks](https://code.claude.com/docs/en/hooks).
